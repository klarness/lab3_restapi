# Лабораторная работа №3. Доска публикаций

## Запуск
Открыть `index.html` в браузере через Live Server в VS Code или двойным кликом по файлу. Нужен доступ в интернет, запросы идут на `jsonplaceholder.typicode.com`.

## Что реализовано
- GET-запрос по кнопке «Загрузить публикации» к `https://jsonplaceholder.typicode.com/posts?_limit=5` через `fetch` + `async/await`, вывод 5 записей через DOM (`textContent`).
- POST-запрос из формы на `https://jsonplaceholder.typicode.com/posts` с заголовком `Content-Type: application/json` и телом `{title, body, userId: 1}`.
- Валидация заголовка и текста (`trim`, непустые значения), `preventDefault` при submit.
- Пока запрос идёт, кнопки блокируются, рядом выводится статус «Загрузка...» или «Отправка...».
- Ошибки сети и неуспешные HTTP-ответы ловятся через `try/catch/finally`, кнопка снова становится активной, на странице появляется сообщение об ошибке.

## Результаты проверки
- Кнопка «Загрузить публикации»: приходят 5 записей, заголовок и текст выводятся на странице.
- Пустые поля или пробелы в форме: показывается «Заполните заголовок и текст публикации», POST не уходит.
- Корректные заголовок и текст: сервер отвечает HTTP 201, на странице выводится ID и заголовок новой записи.
- Подмена адреса GET на `/postz`: в статусе появляется ошибка с кодом HTTP (404), кнопка остаётся активной, запрос можно повторить.
